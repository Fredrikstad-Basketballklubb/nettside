# Nettside for Fredrikstad Basketballklubb

Kildekoden til fredrikstadbasket.no. Siden er ren HTML, CSS og JavaScript og publiseres med GitHub Pages.

- `index.html` – hele siden
- Innhold som treningstider, styre og sponsorer ligger foreløpig som lister i skriptet nederst i `index.html`.

Endringer: si fra til Claude i FBBK-prosjektet, eller rediger filen direkte her på GitHub.
